# 巡境 3DGS 平台 Implementation Plan

**Goal:** 构建以真实 3D Gaussian Splatting 浏览为中心的巡检页面，预留 O1 接入位置。
**Architecture:** 静态前端，Three.js + Spark 在浏览器中解码本地模型；应用状态与渲染分离。合成园区模型以标准 SPLAT 文件提供，首次打开即经过与用户文件相同的加载流程。设备与任务明确为演示，导入用户模型后移除演示坐标。
**Tech Stack:** 原生 ES modules、Three.js 0.180、Spark 2.0、Vite 本地预览。

1. 编写深色全屏控制台：中心视窗、双侧信息、导入入口、底部点位。
2. 生成原创合成园区 SPLAT；接入相机、加载、复位、俯视、旋转、图层。
3. 文件格式校验、错误恢复、资源释放、模型尺寸自动取景；导入后支持自定义点位。
4. 浏览器验收：真实 WebGL 渲染、模型更换、失败后保持原模型、相机交互、响应布局。
5. 编写操作说明与后续 O1 集成边界，发布私有页面并交付本地源码。
