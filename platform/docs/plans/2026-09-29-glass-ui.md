# 悬浮界面毛玻璃视觉调整

用户已修好 3DGS，本轮仅按要求美化悬浮界面。保留现有交互和模型加载逻辑。

采用深色半透明材质，24px 背景模糊、轻微增饱和、细亮边和内高光。顶部导航变为悬浮容器和胶囊选项；侧面卡片、底部工具栏、路线栏与弹窗采用一致圆角。主按钮保留薄荷色，用于识别导入入口。系统字体与中文 PingFang 匹配 Apple 风格。

实现位于 dist/glass.css，由 index.html 在基础样式之后载入。场景铺满视口以使悬浮导航背后也可显示真实场景。未修改任何 JavaScript 或模型文件。

验证：浏览器 1280×720 与 390×844；真实 Garden 背景、导入弹窗、手机场景设置均已检查。透明效果仅用于控件，包含 backdrop-filter 不支持、减少透明度及减少动画的回退样式。
