# 大型 3DGS 加载优化

范围按用户纠正：仅 PLY / SPLAT / SPZ / KSPLAT，不新增 PCD 或点云抽样。

1. 去掉页面 200 MB 硬性限制；仅保留空文件、格式及结构验证。
2. File.slice 每块 4 MiB，通过 ReadableStream 背压交给 Spark 后台解码，避免应用先创建完整 ArrayBuffer，及引擎 fileBytes.slice 的整文件副本。
3. 大模型自动生成 LoD，多精度绘制；流畅/均衡/精细分别调整渲染预算。保留全细节导入模式。
4. 单独显示读取字节进度与解码/优化/取景阶段，包围盒分批计算以避免主线程长循环。
5. 允许加载前主动释放旧模型以降低峰值内存，默认不释放，失败保留旧场景。
6. 验证 >500 MiB 高斯 PLY 加载、原 Garden KSPLAT、SPZ/SPLAT 回归及错误处理；记录浏览器可见结果，不把合成压力测试资产展示为实景。

限制：流式输入和 LoD 不能消除完整解码所需内存，并不承诺无限体积或任意设备流畅。无新增 PCD、服务器地图切片或后台训练。
