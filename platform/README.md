# 巡境 · 3DGS 空间巡检平台

本地可运行的实景 3DGS 查看与巡检标注页面，使用 Three.js + Spark 渲染。默认加载真实照片重建的 Garden 庭院，页面仅提供实景示例和本地模型导入。

## 启动

需要 Node.js 22.12+。

```sh
npm ci
npm run build
npm run assets:demo  # 可选：下载公共实景示例
npm run dev
```

本机浏览器打开 http://127.0.0.1:5273/ 。服务监听所有网络接口，同一局域网设备通过 `http://本机局域网IP:5273/` 访问；IP 可随网络变化。端口固定。构建后的 `dist/` 包含引擎，示例模型由下载命令获取；可由静态 HTTP 服务提供，不要直接使用 `file://`。

## 默认实景

Garden KSPLAT：3,135,539 个高斯，71.91 MiB。来自 GaussianSplats3D 的公开实拍重建示例。模型不纳入代码仓库，可通过 `npm run assets:demo` 下载并验证 SHA-256；使用来源页面的相机位置并校正朝向，复位视角不会被远处异常点干扰。

这不是用户的园区，不是 Odin1 实采成果，也不是绑定经纬度或真实尺度的导航地图。完整来源及文件校验值见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。原有合成场景与开发数据已经移出网页目录；页面不含虚构设备、任务或事件。

## 功能

- 导入或拖入 PLY、SPLAT、SPZ、KSPLAT，不再设置文件体积上限，本地解析、不上传。
- 旋转、平移、缩放、复位、俯视、自动旋转、全屏、专注模式。
- 显示高斯数量、文件体积、帧率；可切换质量和坐标朝向。
- 点击工具栏定位针，再双击模型表面添加点位，支持定位、连线及 JSON 导出。
- 右侧「3DGS 是怎么来的？」介绍拍摄、相机定位、重建训练及浏览的流程。
- 普通点云 PLY 不会自动变为照片级 3DGS；是否可解码取决于具体字段。
- 设备、任务、告警和视频显示未接入状态。

导入另一个场景或刷新会清除点位；需要保留时先导出。点位 JSON 尚不支持再导入和服务器持久化。点位是模型坐标，导出带有 `calibrated:false`。查看器不向机器人下发命令。

## O1 接入所需信息

- 实际导出文件、格式以及是否含高斯属性。
- RGB 图像、深度、相机内参及位姿是否可以获取；若不能直接输出 3DGS，需要独立重建流程。
- 位姿接口、时间戳、单位、坐标轴定义及重定位行为。
- 模型坐标与机器人地图坐标的标定变换。

网页仅负责加载和展示模型，不在浏览器中训练 3DGS。机器人导航、配送调度、视频网关与识别服务尚未接入。

## 独立双地图标定页面

打开 `/calibration.html`。左侧加载 3DGS（PLY / SPLAT / SPZ / KSPLAT），右侧加载 PCD 或点云 PLY。依次添加标定点，在两侧双击同一位置，或在「编辑」中填写原始 XYZ。支持旋转+平移和统一比例校正；至少 3 组不共线标定点，建议 4–6 组及额外独立检查点。

- 检查点不参与拟合。RMS、最大误差与比例均可见，误差不会自动判定为合格；点云单位未确认时仅显示原始单位。
- 「叠加点云」将目标点云反变换到 3DGS 原始坐标，显示青色抽样点用于检查。
- 轴朝向只控制显示，不影响原始坐标、变换或已选点。矩阵约定：行优先 4×4，`p_target = scale * R * p_source + t`，同时导出逆矩阵。
- 可导出 JSON、导入恢复、本机草稿恢复及新建标定。导入结果需要匹配模型后重新计算；自动使用文件首尾 64 KiB 与大小的快速指纹关联，非完整文件完整性验证，严谨版本管理应另存完整文件校验值。
- 点云在 Worker 中完整解码，支持 ASCII / binary / binary_compressed PCD；最多保留 150 万个原始点预览，叠加最多 10 万点。500 MB 等大文件没有人为大小上限，但解码依然消耗内存；抽样可能遗漏细小特征，可输入测量坐标。
- 此页面不执行 ICP，不把 3DGS 高斯中心当作测量级表面，不下发机器人任务，也不修改原始地图。

验证：19 项单元测试通过，包含已知相似变换、刚体变换、共面可解/共线退化、噪声、独立检查点、逆矩阵、单位及三种 PCD 编码。浏览器验证双地图导入、双击选点、精确编辑、叠加、轴朝向、JSON 下载与恢复；使用测试数据验证比例 1.5 和独立检查点 2 cm 偏差。测试素材仅位于 `artifacts/calibration-test/`，不作为页面默认地图。

## 标定页漫游与去噪

- 左侧默认漫游，两侧均可切换漫游 / 旋转 / 平移。点击画面激活键盘，WASD 沿视线前后和横移，Q 下降 / E 上升，Shift 加速，按住左键拖动转头。Esc 或失焦停止移动；速度可选慢速、正常、快速。
- 右侧默认轻度孤立点去噪，可改为标准、较强或关闭。后台计算邻点支持度，只过滤显示和新选点，不改原始文件与既有标定点坐标。稀疏的有效结构也可能被过滤，可降低强度；密集漂浮簇不能保证被清除。
- 点云选点优先选择点击范围内的前方表面，再选择该表面层中最接近点击的原始顶点；隐藏噪点不参与拾取。
- 19 项测试覆盖坐标变换、文件解析、原始坐标保留、去噪、过滤后的射线拾取和前后表面选择。
