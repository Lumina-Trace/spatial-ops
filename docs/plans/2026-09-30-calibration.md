# 双地图标定工作台

独立标定工具，首页 / 直接进入双地图工作台，/calibration.html 兼容跳转。沿用 Apple 毛玻璃视觉。

工作流：加载本地 3DGS 与 PCD/PLY 点云 → 逐组在左右双击选点（可输入已知坐标）→ 求刚体/统一尺度相似变换 → 目标点云反向叠加到 3DGS → 用独立检查点核验 → 导出或导入版本化 JSON。

数据约定：一律保存文件原始坐标，轴朝向仅影响显示；T_source_to_target 行优先矩阵，p_target=sR p_source+t。目标单位显式设置，未知时不显示厘米。模型指纹由文件首尾内容、尺寸生成，明确是快速指纹；导入文件必须匹配才能恢复选点和叠加。标定参数不自动控制机器人，不声称已验证精度。

计算：Horn quaternion + Jacobi eigen，三组以上非共线点；检查点不参与拟合；报告拟合/检查 RMS、最大误差及尺度。修改点、模式、单位、模型后使旧结果失效。

性能：3DGS 分块读取；PCD/PLY 在 Worker 解析（包含 binary_compressed PCD），点云最多保留 150 万真实点预览、叠加最多 10 万点；明确显示抽样数量，仍需完整解码内存。无 ICP 自动配准，无服务端上传。

验证：已知变换、含噪数据、退化点、单位/逆变换、文件恢复验证；浏览器实际加载并选点、算出结果、叠加、导出、移动布局。测试素材必须清楚标为测试，不代替真实地图。
