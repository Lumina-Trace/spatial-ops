# 标定页自由漫游与点云去噪

左侧默认自由漫游；右侧也可选择。点击视窗后 WASD 沿视线前后 / 横移，Q/E 沿显示空间竖直升降，Shift 四倍速，拖动鼠标原地转头，滚轮沿视线移动。慢速 / 正常 / 快速按模型尺度适配。Esc、失焦、切换模式与页面隐藏均停止移动；表单输入不接管键盘。保留旋转、平移和俯视。

点云 Worker 在最多 150 万个预览原始点上分析半径邻居支持度。鲁棒包围范围和抽样最近邻估计自动半径，轻度 / 标准 / 较强要求 2 / 4 / 7 个邻点；可关闭。通过 geometry index 同时控制显示和拾取，不平滑、不移动原始坐标。少于 32 点或无空间跨度时跳过去噪。去噪是孤立点过滤，不能清除密集的漂浮簇，稀疏有效结构可能需要降低强度。

拾取先限制屏幕像素距离，再取最靠近相机的表面层内最接近点击的真实顶点，避免背景点因更接近鼠标射线抢先。叠加预览跟随过滤索引。已有标定点保持原始坐标不变。

验证：19 个自动测试通过；检查平面边界保留、悬空单点 / 点对移除、单位与朝向不变性、实际 Three.js raycast 不拾取隐藏点、前后表面选择。150 万点合成曲面在本机分析约 2.2 秒，仅作算法基准。浏览器加载实景 Garden 验证 W/A、拖动转头和焦点；点云测试 20,030 点保留 20,000 点，关闭过滤恢复全部点，双击记录到 z=0 的原始表面点。右侧测试素材只用于验证，不作为真实地图交付。
